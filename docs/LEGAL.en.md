# Legal and licensing overview

This document is not legal advice.

## Original code

Original repository code and project-created documentation are MIT-licensed unless a file explicitly states otherwise.

## What is NOT automatically covered by MIT?

- Star Citizen / CIG / RSI trademarks and IP.
- UEX data and services.
- Star Citizen Wiki data/content.
- SCMDB_DATA data.
- Reddit and other community-source content.

## Fan-site notice

The V055 HTML includes a visible bilingual notice stating that it is an unofficial community tool and links to the official RSI site.

## Commercial use

The integrated Star Citizen/UEX/Wiki use is designed as non-commercial fan use. The MIT code license cannot override third-party service and fandom terms.

## Data redistribution

The package intentionally contains no upstream data dumps. Live data are fetched at runtime and only a local operational snapshot is created in the user's browser.
