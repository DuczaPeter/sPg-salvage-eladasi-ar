# User guide

## CMAT

1. Select a salvage ship.
2. Enter raw structural salvage SCU before refining.
3. Select `Refine + Sell` or `Sell Only`.
4. For refining, choose Dinyx or Pyrometric.
5. Apply location and Top 3 / All filters.
6. The large CMAT heading opens the UEX demand page.
7. A result location opens the exact UEX terminal demand view.

## RMC

1. RMC amount is optional for viewing prices.
2. Enter SCU to calculate total revenue.
3. Use the same location and result filters.
4. The large RMC heading and result locations open UEX demand views.

## What does UNKNOWN mean?

The app could not prove the relevant access/mechanic field from source evidence. It does not invent an answer; it safely excludes the item from decisions that require proof.

## Cache

`Clear cache` removes the local IndexedDB snapshot/preferences according to app rules. Refreshing then fetches current source data again.
